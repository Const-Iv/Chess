# Импорт deep-research базы дебютов, 2026-05-09

## Связь с charter проекта

Импорт поддерживает миссию тренажера: помогать шахматисту-любителю понимать и запоминать основные дебюты через подсказки по ходам, названия вариантов и планы перехода к миттельшпилю.

## Цель изменения

Расширить базу с маленького набора curated examples до удобного учебного каталога: 98 линий с приоритетами, PGN, планами сторон, табиями, ключевыми идеями и подсказками на каждый полуход.

## Проверка источника

Локальная проверка `lichess_prefix_validation_2026-05-09.json`:

| Проверка | Результат |
| --- | ---: |
| Всего imported variations | 98 |
| SAN legal через `chess.js` strict mode | 98 |
| Полный PGN совпадает с Lichess `chess-openings` | 20 |
| Линия продолжает известный Lichess-префикс | 78 |

Для `lichess-prefix` карточек приложение не утверждает, что дополнительные ходы являются отдельной Lichess opening-name записью или engine-best. Они показаны как учебное продолжение из imported research.

## Ограничения

- Lichess Explorer статистика по рейтингу пока не подключена.
- Stockfish sanity check пока не подключен.
- Imported research не заменяет будущий positions/FEN tree; текущий слой уже дает app-ready карточки и строгую проверку легальности линий.

## Критерии приемки

- Пользователь видит 98 imported линий плюс curated core-карточки в одном тренажере.
- Каждая imported карточка показывает планы сторон, табию, ключевые идеи и подсказки на ходы.
- Все SAN-линии проходят deterministic legal-move check.
- Источник и степень проверки не скрыты от пользователя.
